KYK管理システム Version 1.4.0（第一段階）

【追加機能】
・トップ画面を「KYK管理」「日誌管理」に分割
・KYから現場名＋作業日単位の日誌を複数選択で自動作成
・日誌作成済み一覧（現場名、作業日、元請連絡未記入のみ）
・元請連絡6行（各55文字）、品質に関する事項6行（各40文字）
・日誌削除（非表示削除）と再作成
・KYK情報を更新ボタン（自動更新はしません）
・現在表示中の日誌を1つのExcelへ複数シート出力
・KYK・日誌データの安全バックアップ

【重要】
・このZIPにはKYKDBを同梱していません。KYKDBは従来どおり別管理してください。
・初回またはDB更新時は右上の「KYKDB再読込」から KYKDB(Ver.1.2).xlsx を読み込んでください。
・アプリ更新時、端末に保存済みのKYKDBとKYK・日誌データを引き継ぎます。
・GitHubへは、このZIP内のアプリファイルをすべて上書きしてください。KYKDBは別途配置・管理してください。

【第二段階予定】
・KYK一括PDF出力
・日誌一括PDF出力
・ホーム画面の未処理件数表示
・細かなUI改善と速度最適化
