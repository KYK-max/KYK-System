KYK管理システム Version 0.2.5

修正内容
・Excel出力時にKYK原本シートを削除せず、そのまま第1シートとして使用する方式へ変更
・2件目以降はKYK原本シートと関連ファイルを複製
・罫線、文字、セル結合、印刷設定などの原本書式を維持
・保存データを各KYKシートへ反映
・同一現場の一括出力は1ブック内の複数シート
・Service Workerのキャッシュ名を更新

注意
以前の版をPWAとして登録している場合は、Version 0.2.5のindex.htmlを一度開き直してください。
ブラウザーが古い画面を表示する場合は、再読み込みしてください。

KYK管理システム Version 0.2.1

■起動
index.html を開いてください。Webサーバー上で使用するとPWAとして利用できます。

■初回設定
右上の「KYKDB読込」から KYKDB(2).xlsx を選択します。
読み込んだExcel原本はブラウザーのIndexedDBに保存され、次回以降は自動復元されます。
KYKDBを修正した場合だけ、同じボタンから再読込してください。

■Version 0.2.1 修正内容
・Excel出力時にKYK入力内容が反映されるよう、KYKシートをシート名から特定
・個別Excel出力を維持
・保存済一覧に「選択現場を一括Excel出力」を追加
・同一現場の保存データを、1つのExcelブック内の複数KYKシートとして出力
・シート名は「会社名シート表示マスター_月日」
・同じシート名が重なる場合は _2、_3 の連番を付加
・一括出力は保存済みデータから最新版の現場ブックを毎回再作成

■一括出力の使い方
1. 保存済一覧を開きます。
2. 現場名を1つ選択します。
3. 必要に応じて会社名でも絞り込みます。
4. 「選択現場を一括Excel出力」を押します。
5. 表示中の全データが、1つの現場Excelファイル内に複数シートで出力されます。

■注意
・複数現場を同時に1ファイルへまとめることはせず、現場名を1つ選択して出力します。
・ブラウザーのサイトデータを削除した場合や別端末ではKYKDBを再読込してください。
・KYKDBの行列挿入、セル結合範囲変更、シート名変更は出力位置へ影響します。
・Excel処理用SheetJSは初回起動時にインターネットから読み込まれます。
