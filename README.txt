KYK管理システム Version 1.4.2

【主な修正】
・KYK保存済み一覧に個別PDF出力と表示中一括PDF出力を追加
・KYK／日誌のPDF出力は、入力画面ではなくExcel帳票にデータを反映した内容を基準に印刷表示
・日誌一括PDFは、現在表示中の日誌を1つの複数ページPDFとして保存可能
・端末内5世代バックアップを廃止
・バックアップは「バックアップ作成」「バックアップから復元」の2機能に整理
・トップ画面の保存済みKY、元請確認待ち、作成済み日誌、元請連絡未記入の件数をバックアップ欄の上に配置
・Excel／PDFなどのボタン同士が接触して見えないよう余白を拡大

【PDF保存方法】
PDF出力を押すと帳票印刷画面が開きます。iPadでは共有または印刷画面からPDFとして保存してください。

【重要】
・このZIPにはKYKDB.xlsxを同梱していません。
・KYKDBは右上の「KYKDB再読込」から手動で読み込んでください。
・バックアップZIPにもKYKDB.xlsx本体は含みません。
